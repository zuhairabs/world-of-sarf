# Curriculum Adventure Coverage

The supplied curriculum contains ten abwaab across Lessons 10–14. Sarf Quest
now creates one adventure bundle per baab. Each bundle has six playable
quests:

1. Pattern Lanterns — Seegha Match
2. Root Forge — Word Builder
3. Baab Detective
4. Sarf Speed Run
5. Tasreef Table — Complete the Tasreef
6. Baab Guardian — mixed Boss Battle

The typed source records live in `my-app/src/content/data/curriculum.ts` and
the generated quest bundles live in
`my-app/src/content/data/adventures.ts`. The campaign index is rendered in the
world-map field journal so mobile players can reach every baab and every game.

All current OCR-derived records and generated questions are marked
`needs_review`. Lesson 10 is explicitly labelled as unconfirmed in the source
notes. The uncertain باب افعيعال خلج entry is not included in the playable
examples.
