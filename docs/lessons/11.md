## باب تفعيل

### Core Pattern

Any verb of ثلاثي مجرد that comes in باب تفعيل follows the pattern below in ماضي، مضارع, and مصدر:

| Scale   | ماضي    | مضارع     | مصدر     |
| ------- | ------- | --------- | -------- |
| Pattern | فَعَّلَ | يُفَعِّلُ | تَفْعِيل |

### Examples

| Root | ماضي    | مضارع     | مصدر     | Meaning                             |
| ---- | ------- | --------- | -------- | ----------------------------------- |
| علم  | عَلَّمَ | يُعَلِّمُ | تَعْلِيم | He taught                           |
| صدق  | صَدَّقَ | يُصَدِّقُ | تَصْدِيق | He affirmed / ascribed truthfulness |
| وحد  | وَحَّدَ | يُوَحِّدُ | تَوْحِيد | He declared to be One               |

### Other Applications

| امر غائب    | امر حاضر | جحد            | نهي          | نفي          | استفهام        |
| ----------- | -------- | -------------- | ------------ | ------------ | -------------- |
| لِيُفَعِّلْ | فَعِّلْ  | لَمْ يُفَعِّلُ | لا يُفَعِّلْ | لا يُفَعِّلُ | هَلْ يُفَعِّلُ |
| لِيُعَلِّمُ | عَلِّمْ  | لَمْ يُعَلِّمُ | لا يُعَلِّمُ | لا يُعَلِّمُ | هَلْ يُعَلِّمُ |
| لِيُوَحِّدُ | وَحِّدْ  | لَمْ يُوَحِّدُ | لا يُوَحِّدُ | لا يُوَحِّدُ | هَلْ يُوَحِّدُ |

## Meanings of باب تفعيل

### 1. Making a Verb Transitive (متعدي)

Converts an intransitive verb into one that acts on an object.

| لازم   | Meaning         | →   | متعدي   | Meaning                         |
| ------ | --------------- | --- | ------- | ------------------------------- |
| نَزَلَ | He came down    | →   | نَزَّلَ | He sent down                    |
| فَرِحَ | He became happy | →   | فَرَّحَ | He made [someone] happy         |
| بَعُدَ | He became far   | →   | بَعَّدَ | He made [someone/thing] distant |

### 2. Attributing an Action to the Object (مفعول)

To relate or ascribe a quality or action to someone.

| Arabic               | Translation                        |
| -------------------- | ---------------------------------- |
| كَفَّرْتُ سَعِيدًا   | I attributed disbelief to Saeed.   |
| كَذَّبْتُ مَسْعُودًا | I related a lie to Mas'ood.        |
| صَدَّقْتُ حَمِيدًا   | I ascribed truthfulness to Hameed. |
| وَحَّدْتُ اللهَ      | I attributed unity to Allah.       |

## باب مفاعلة

### Core Pattern

Any verb of ثلاثي مجرد that comes in باب مفاعلة follows the pattern below in ماضي، مضارع, and مصدر:

| Scale   | ماضي    | مضارع     | مصدر       |
| ------- | ------- | --------- | ---------- |
| Pattern | فَاعَلَ | يُفَاعِلُ | مُفَاعَلَة |

### Examples

| Root | ماضي    | مضارع     | مصدر       | Meaning                           |
| ---- | ------- | --------- | ---------- | --------------------------------- |
| كتب  | كَاتَبَ | يُكَاتِبُ | مُكَاتَبَة | They corresponded with each other |
| قتل  | قَاتَلَ | يُقَاتِلُ | مُقَاتَلَة | They fought each other            |
| بحث  | بَاحَثَ | يُبَاحِثُ | مُبَاحَثَة | They discussed with each other    |

### Other Applications

| امر غائب    | امر حاضر | جحد            | نهي          | نفي          | استفهام        |
| ----------- | -------- | -------------- | ------------ | ------------ | -------------- |
| لِيُفَاعِلْ | فَاعِلْ  | لَمْ يُفَاعِلُ | لا يُفَاعِلْ | لا يُفَاعِلُ | هَلْ يُفَاعِلُ |
| لِيُقَاتِلُ | قَاتِلُ  | لَمْ يُقَاتِلُ | لا يُقَاتِلُ | لا يُقَاتِلُ | هَلْ يُقَاتِلُ |
| لِيُبَاحِثُ | بَاحِثُ  | لَمْ يُبَاحِثُ | لا يُبَاحِثُ | لا يُبَاحِثُ | هَلْ يُبَاحِثُ |

## Meaning of باب مفاعلة: Co-operation and Reciprocity

Any action that the subject executes on the object is also reciprocated by the object on the subject.

| Arabic                   | Meaning                                         |
| ------------------------ | ----------------------------------------------- |
| ضَرَبَ عَلِيٌّ سَعِيدًا  | Ali beat Saeed (one-sided action)               |
| ضَارَبَ عَلِيٌّ سَعِيدًا | Ali and Saeed fought each other (mutual action) |
| كَاتَبَ عَلِيٌّ حَسَنًا  | Ali and Hasan corresponded with each other      |
| بَاحَثَ                  | Discussed with each other                       |
| ضَاحَكَ                  | Made fun of each other                          |

## Important Note: حروف مضارعة

In ثلاثي مجرد the حروف مضارعة (ن، ت، ي، أ) are always مفتوح (fathah).

However, in those abwaab whose ماضي consists of **four letters** (أفْعَلَ، فَعَّلَ، فَاعَلَ), the حروف مضارعة become **مضموم** (dammah):

| ماضي     | مضارع     |
| -------- | --------- |
| أَكْرَمَ | يُكْرِمُ  |
| عَلَّمَ  | يُعَلِّمُ |
| خَادَعَ  | يُخَادِعُ |

## Exercises

1. Write the مضارع and مصدر of: عَلَّمَ، وَحَّدَ
2. Write the مضارع and مصدر of: قَاتَلَ، جَالَسَ
3. Write the امر حاضر, امر غائب, and نهي of: عَلَّمَ، قَاتَلَ
4. What are the two common aspects (sign of مضارع) shared by all three abwaab studied so far?
5. Translate and put into باب تفعيل: نَزَلَ (came down)، فَسَدَ (became corrupted)، قَرُبَ (became near)
6. Translate: تَوْحِيد
7. What does co-operation and mutual action mean in باب مفاعلة?
8. Translate: ضَاحَكَ، بَاحَثَ
9. When do the حروف مضارعة become مضموم? Give 3 examples.
