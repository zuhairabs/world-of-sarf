## Introduction

When there are three alphabets in the root of a verb, it is called **ثلاثي**.
Examples: كَتَبَ، ضَرَبَ، نَصَرَ، قَتَلَ

When the root is comprised of four alphabets, it is called **رباعي**.
Examples: دَحْرَجَ، وَسْوَسَ، زَلْزَلَ

If these verbs have no additional alphabet in their root, they are called **مجرد**:

- ثلاثي مجرد: كَتَبَ
- رباعي مجرد: زَلْزَلَ

If these verbs contain one or more additional alphabets in the root, they are termed **مزيد** (additives):

- ثلاثي مزيد: كَاتَبَ (root: كتب with ا added)
- رباعي مزيد: تَزَلْزَلَ (root: زلزل with ت added)

## Classification of Root Words

Root words are broadly classified under four heads:

| #   | Category   | Examples               |
| --- | ---------- | ---------------------- |
| 1   | ثلاثي مجرد | كَتَبَ، ضَرَبَ         |
| 2   | ثلاثي مزيد | كَاتَبَ، ضَارَبَ       |
| 3   | رباعي مجرد | زَلْزَلَ، وَسْوَسَ     |
| 4   | رباعي مزيد | تَزَلْزَلَ، تَوَسْوَسَ |

## باب افعال

### Core Pattern

| ماضي     | مضارع    | مصدر     |
| -------- | -------- | -------- |
| أَفْعَلَ | يُفْعِلُ | إِفْعَال |

> **Note:** Every فعل ماضي that has a hamza (أ) at the beginning loses this hamza in the مضارع.  
> The hamza of أمر حاضر in باب افعال is always مفتوح (fathah). Examples: أَحْسِنْ، أَنْزِلْ، أَجْلِسْ، أَكْرِمْ.

### Other Applications

| امر غائب   | امر حاضر | جحد           | نهي         | نفي         | استفهام       |
| ---------- | -------- | ------------- | ----------- | ----------- | ------------- |
| لِيُفْعِلْ | أَفْعِلْ | لَمْ يُفْعِلُ | لا يُفْعِلُ | لا يُفْعِلُ | هَلْ يُفْعِلُ |

## Functions of باب افعال

### 1. Making an Intransitive Verb Transitive (متعدي)

**فعل لازم** — a verb that needs only a subject (no object):

- Example: جَلَسَ عَلِيٌّ (Ali sat) — Ali is the subject; no object is needed.

**فعل متعدي** — a verb that needs both a subject and an object:

- Example: نَصَرَ عَلِيٌّ حَسَنًا (Ali helped Hasan) — both subject and object are required.

| لازم                    | →   | متعدي                               |
| ----------------------- | --- | ----------------------------------- |
| جَلَسَ (He sat)         | →   | أَجْلَسَ (He made [someone] sit)    |
| حَسُنَ (He became good) | →   | أَحْسَنَ (He obliged / did good to) |
| نَزَلَ (He came down)   | →   | أَنْزَلَ (He sent down)             |

### 2. Finding an Attribute in the Subject (فاعل)

This function means: to find or perceive a quality in someone.

Examples:

- أَبْخَلْتُ سَعِيدًا — I found Saeed to be a miser.
- أَكْبَرْتُ عَلِيًّا — I found Ali to be great.
- أَعْظَمْتُ اللهَ — I found Allah to be Glorious.
- أَظْلَمْتُ سَعُودًا — I found Saood to be an oppressor.
