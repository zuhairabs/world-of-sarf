## Classification by Added Letters

### One Letter Added

| Baab   | Added Letter       | Example  |
| ------ | ------------------ | -------- |
| افعال  | أ (hamza) at start | أَكْرَمَ |
| تفعيل  | شدّة on عين الفعل  | عَلَّمَ  |
| مفاعلة | أ (alif) after فاء | كَاتَبَ  |

### Two Letters Added

| Baab   | Added Letters           | Example   |
| ------ | ----------------------- | --------- |
| تفاعل  | تَ + أ (alif)           | تَعَاوَنَ |
| تفعّل  | تَ + شدّة on عين        | تَعَلَّمَ |
| افتعال | أ (hamza) + ت           | اجْتَمَعَ |
| انفعال | أ (hamza) + ن           | انْكَسَرَ |
| افعلال | أ (hamza) + شدّة on لام | احْمَرَّ  |

### Three Letters Added

| Baab    | Added Letters                        | Example     |
| ------- | ------------------------------------ | ----------- |
| استفعال | أ + س + ت                            | اسْتَغْفَرَ |
| افعيعال | أ + و (inserted) + repetition of عين | اعْشَوْشَبَ |
