## باب افعلال

### Core Pattern

Any verb of ثلاثي مجرد that comes in باب افعلال follows the pattern below in ماضي، مضارع, and مصدر:

| Scale   | ماضي     | مضارع     | مصدر      |
| ------- | -------- | --------- | --------- |
| Pattern | افْعَلَّ | يَفْعَلُّ | افْعِلَال |

> **Note:** In أمر حاضر, أمر غائب and in the جحد forms, the last letter of this باب carries a شدّة and does **not** become ساكن. One may read it with either فتحة or كسرة.

### Examples

| Root | ماضي     | مضارع     | مصدر      | Meaning                    |
| ---- | -------- | --------- | --------- | -------------------------- |
| حمر  | احْمَرَّ | يَحْمَرُّ | احْمِرَار | It became completely red   |
| خضر  | اخْضَرَّ | يَخْضَرُّ | اخْضِرَار | It became completely green |
| عوج  | اعْوَجَّ | يَعْوَجُّ | اعْوِجَاج | It became crooked / bent   |

> **OCR correction:** The form يَعْرَجُ in the original scan was an OCR error (confused root عرج for عوج). The correct مضارع of اعْوَجَّ is يَعْوَجُّ.

### Other Applications

| امر غائب    | امر حاضر | جحد            | نهي          | نفي          | استفهام        |
| ----------- | -------- | -------------- | ------------ | ------------ | -------------- |
| لِيَفْعَلَّ | افْعَلَّ | لَمْ يَفْعَلَّ | لا يَفْعَلَّ | لا يَفْعَلُّ | هَلْ يَفْعَلُّ |
| لِيَحْمَرَّ | احْمَرَّ | لَمْ يَحْمَرَّ | لا يَحْمَرَّ | لا يَحْمَرُّ | هَلْ يَحْمَرُّ |
| لِيَعْوَجَّ | اعْوَجَّ | لَمْ يَعْوَجَّ | لا يَعْوَجَّ | لا يَعْوَجُّ | هَلْ يَعْوَجُّ |

## Meaning of باب افعلال

This باب shows **complete colouring** or the **presence of a defect**.

**Examples of colours:**
| Arabic | Meaning |
|---|---|
| احْمَرَّ | It became completely red |
| اخْضَرَّ | It became completely green |
| اصْفَرَّ | It became completely yellow |
| ابْيَضَّ | It became completely white |
| ازْرَقَّ | It became completely blue |

**Examples of defects:**
| Arabic | Meaning |
|---|---|
| اعْوَرَّ | He became one-eyed |
| اعْوَجَّ | He/it became crooked |

## Meaning of باب استفعال

The فاعل (subject) **seeks** something from the مفعول (object).

| Arabic      | Meaning                                  |
| ----------- | ---------------------------------------- |
| اسْتَغْفَرَ | He sought forgiveness                    |
| اسْتَكْبَرَ | He sought greatness (i.e., was arrogant) |
| اسْتَعْلَمَ | He sought knowledge                      |
| اسْتَفْهَمَ | He sought understanding / He asked       |

## Meaning of باب افعيعال: Exaggeration or Excess

| Arabic                   | Meaning                             |
| ------------------------ | ----------------------------------- |
| عَشِبَ → اعْشَوْشَبَ     | It grew → It grew a lot             |
| مَطَرَ → امْطَوْطَرَ     | It rained → It rained heavily       |
| ثَلَجَ → اثْلَوْثَجَ [?] | It snowed → It snowed heavily       |
| خَشُنَ → اخْشَوْشَنَ     | It was rough → It became very rough |

## Classification of All 10 Abwaab of ثلاثي مزيد

All ten abwaab can be grouped by the number of letters added to the root:

| Added Letters       | Abwaab                                               |
| ------------------- | ---------------------------------------------------- |
| One letter added    | أَفْعَلَ، فَعَّلَ، فَاعَلَ                           |
| Two letters added   | تَفَعَّلَ، تَفَاعَلَ، افْتَعَلَ، انْفَعَلَ، افْعَلَّ |
| Three letters added | اسْتَفْعَلَ، افْعَوْعَلَ                             |

**Key rule:** Every فعل ماضي that has an extra hamza (أ) at the beginning loses this hamza in the مضارع:

| ماضي        | مضارع        |
| ----------- | ------------ |
| أَفْعَلَ    | يُفْعِلُ     |
| افْتَعَلَ   | يَفْتَعِلُ   |
| انْفَعَلَ   | يَنْفَعِلُ   |
| افْعَلَّ    | يَفْعَلُّ    |
| اسْتَفْعَلَ | يَسْتَفْعِلُ |

## Exercises

1. Give two examples on the scale of افْعَوْعَلَ.

3. Conjugate six seeghas of مخاطب and two seeghas of متكلم in مضارع of: اسْتَغْفَرَ

6. What is the meaning of باب افعلال? Give one example.
7. Translate: اسْتَفْهَمَ، اخْضَرَّ، اسْتَكْبَرَ، اعْوَرَّ، اعْشَوْشَبَ، امْطَوْطَرَ
