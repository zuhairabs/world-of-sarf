## باب تفاعل

### Core Pattern

Any verb of ثلاثي مجرد that comes under باب تفاعل follows the pattern below in ماضي، مضارع, and مصدر:

| Scale   | ماضي      | مضارع       | مصدر     |
| ------- | --------- | ----------- | -------- |
| Pattern | تَفَاعَلَ | يَتَفَاعَلُ | تَفَاعُل |

### Examples

| Root | ماضي      | مضارع       | مصدر     | Meaning                            |
| ---- | --------- | ----------- | -------- | ---------------------------------- |
| عون  | تَعَاوَنَ | يَتَعَاوَنُ | تَعَاوُن | They helped each other             |
| جوز  | تَجَاوَزَ | يَتَجَاوَزُ | تَجَاوُز | They went beyond / they overlooked |
| مرض  | تَمَارَضَ | يَتَمَارَضُ | تَمَارُض | He feigned sickness                |

### Other Applications

| امر غائب      | امر حاضر  | جحد              | نهي            | نفي            | استفهام          |
| ------------- | --------- | ---------------- | -------------- | -------------- | ---------------- |
| لِيَتَفَاعَلْ | تَفَاعَلْ | لَمْ يَتَفَاعَلُ | لا يَتَفَاعَلُ | لا يَتَفَاعَلُ | هَلْ يَتَفَاعَلُ |
| لِيَتَعَاوَنُ | تَعَاوَنْ | لَمْ يَتَعَاوَنُ | لا يَتَعَاوَنُ | لا يَتَعَاوَنُ | هَلْ يَتَعَاوَنُ |
| لِيَتَمَارَضُ | تَمَارَضْ | لَمْ يَتَمَارَضُ | لا يَتَمَارَضُ | لا يَتَمَارَضُ | هَلْ يَتَمَارَضُ |

## Meanings of باب تفاعل

### 1. Partnership and Co-operation

Shows a reflexive or mutual action among multiple subjects.

| Arabic              | Meaning                               |
| ------------------- | ------------------------------------- |
| تَضَارَبَ الْقَوْمُ | The people fought with each other     |
| تَعَاوَنَ           | They helped each other (co-operation) |

### 2. Feigning an Action

The subject pretends or simulates the action without actually doing it.

| Arabic            | Meaning                                      |
| ----------------- | -------------------------------------------- |
| تَمَارَضَ عَلِيٌّ | Ali feigned sickness (while he was not sick) |
| تَنَابَلَ سَعِيدٌ | Saeed pretended to be lazy                   |
| تَجَاهَلَ حَسَنٌ  | Hasan feigned ignorance                      |

| ------- | --------- | ----------- | -------- |

### Examples

| ---- | --------- | ----------- | -------- | --------------------- |

## Meaning of باب تفعّل: Acceptance of Effect

The object (مفعول) accepts or receives the consequence of the action performed upon it.

| Arabic                         | Translation                                                                  |
| ------------------------------ | ---------------------------------------------------------------------------- |
| عَلَّمْتُ زَيْدًا فَتَعَلَّمَ  | I taught Zaid, then he learned (i.e., he accepted the result of my teaching) |
| فَهَّمْتُ عَلِيًّا فَتَفَهَّمَ | I made Ali understand, then he understood                                    |

## Grammar Notes

### Note 1: Dropping of Doubled ت

In باب تفاعل and باب تفعّل, if two تاء letters come adjacent in مضارع (for seegha nos. 4, 5 and 7–12), one is dropped for ease of pronunciation:

| Original    | Simplified  |
| ----------- | ----------- |
| تَتَعَاوَنُ | → تَعَاوَنُ |
| تَتَمَارَضُ | → تَمَارَضُ |
| تَتَعَلَّمُ | → تَعَلَّمُ |

### Note 2: Assimilation Rule for Eleven Letters

When the فاء الفعل is any of the following eleven letters: **ث، د، ذ، ز، ش، ص، ض، ط، ظ** in either باب تفاعل or باب تفعّل, the تاء of the pattern is changed to match the فاء الفعل, and the law of إدغام is applied:

**Example:** زَيَّنَ (root: زين)

1. تَزَيَّنَ (original تفعّل form)
2. زَزَيَّنَ (ت assimilated to ز)
3. إِزَّيَّنَ (إدغام applied, hamza added at start)

**Other examples:**

- ذَكَرَ → تَذَكَّرَ → ذَذَكَّرَ → إِذَّكَّرَ
- ثَقَلَ → تَثَاقَلَ → ثَثَاقَلَ → إِثَّاقَلَ

### Qur'anic Examples of This Rule

| Verse                                      | Reference   |
| ------------------------------------------ | ----------- |
| إِنَّا ثَقُلْتُمْ إِلَى الْأَرْضِ          | توبه: 38    |
| مَا يَذَّكَّرُ إِلَّا أُولُوا الْأَلْبَابِ | بقره: 269   |
| فَأَصَّدَّقَ                               | منافقون: 10 |

## Exercises

1. Write the مضارع of: تَبَاعَدَ، تَجَاوَزَ، and تَقَدَّسَ
2. In تَزَيَّنَ، تَنَزَّلَ، and تَبَاعَدَ — what are the root letters?
3. Translate: تَضَارَبَ الْقَوْمُ
4. Translate: تَمَارَضَ عَلِيٌّ and تَنَابَلَ حَسَنٌ
5. What does عَلَّمْتُ عَلِيًّا فَتَعَلَّمَ mean?
6. What is the difference between: (a) تَفْعِيل and تَفَعُّل, (b) تَعْلِيم and تَعَلُّم?
